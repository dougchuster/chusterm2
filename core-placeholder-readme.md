# core/ — Fork do Chatwoot CE

Esta pasta deve conter o fork privado do **Chatwoot Community Edition**.

## Como configurar

```bash
# 1. No GitHub: criar fork privado de https://github.com/chatwoot/chatwoot
# 2. Clonar aqui:
git clone git@github.com:SUA_ORG/chatwoot.git .

# 3. Adicionar upstream para sincronização mensal
git remote add upstream https://github.com/chatwoot/chatwoot.git
```

Consulte [../SETUP.md](../SETUP.md) para o guia completo.
